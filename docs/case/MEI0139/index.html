Abdelhak et al. 1997 · Hum Mol Genet · PMID 9361030 · coded from abstract
Clustering of mutations responsible for branchio-oto-renal (BOR) syndrome in the eyes absent homologous region (eyaHR) of EYA1.
Coding disruption A de novo Alu element inserted into an EYA1 coding exon (found by coding-region sequencing) in a BOR patient, presumably disrupting the protein; the poly(A) tail was unstable across generations. Transcript effect not studied in abstract.
“one mutation comprises a de novo Alu insertion into an exon”
