What the papers report

1 report
Sabbagh et al. 2025 · Clin Epigenetics · PMID 40301896 · coded from full text
Reverse genotyping: unveiling Alu element insertion as a new cause of Kabuki syndrome using DNA methylation signature.
Coding disruption A heterozygous de novo AluY (281 bp core + 38 bp poly(A), 16-bp TSD) in KMT2D exon 36, found by reanalysis after a Kabuki DNA methylation episignature, is predicted to cause a frameshift p.(Lys3436Glyfs*40) and loss of function; no RNA/protein studies.
“According to VariantValidator, such heterozygous de novo insertion is anticipated to result in KMT2D loss-of-function by inducing the following truncating variant: NM_003482.4 (NP_003473.3):p.(Lys3436Glyfs*40) (GRCh37/hg19).”
