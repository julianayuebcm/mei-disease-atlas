Example: SPINK1

Severe infantile isolated exocrine pancreatic insufficiency
Coding exonUTRInsertion (▶ sense, ◀ antisense)

The homozygous 3' UTR Alu insertion abolishes SPINK1 mRNA; a 3' UTR reporter showed only ~50% reduction, whereas full-length gene assays showed the loss results from dsRNA structures formed between the inserted Alu and two oppositely oriented Alus in intron 3, with expression restored when all three Alus were placed in the same orientation.
