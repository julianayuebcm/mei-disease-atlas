About the atlas

The MEI Disease Atlas collects published germline mobile element insertions that cause human disease and codes how each one breaks its gene, so the literature can be searched by gene, element and mechanism in one place.

Author

Juliana Yue
Baylor College of Medicine

Corrections and missing cases are welcome: open an issue on the GitHub repository.

How to cite

Yue J. MEI Disease Atlas: germline mobile element insertions in human disease (version 2026-11-03). https://julianayuebcm.github.io/mei-disease-atlas/

Please also cite the original papers for any case you use; each case page links to them on PubMed.

Disclaimer

Records were extracted from 436 papers with the help of a large language model (Claude, Anthropic) and merged automatically. They have been only partly checked by hand and may contain errors. Always confirm details in the original publication.

This resource is for research and education. It is not a clinical database and must not be used for diagnosis or patient care decisions.

The atlas contains only information from published literature and public gene annotation (GENCODE v38). It contains no patient data.
